# Jellyfin Metadata Localizer

[English](README.md)

为 Jellyfin 管理员提供电影标题、完整 NFO 简介和类型的翻译管理。可以先查看、编辑翻译候选，再应用到媒体库的共享显示，并保留原文记录和恢复历史。

**0.11.0-preview.1 · Windows x64 · 仅 Jellyfin 12.0.0 · .NET 10**

当前是预览候选，尚未公开发布。本地检查与限制见[验证说明](docs/VALIDATION.md)；GitHub Actions 结果按各次提交单独记录。

## 功能

- 将电影标题、完整 NFO 简介翻译为简体中文或英文。
- 查看、编辑、批准候选，将原文、选中候选和实际应用记录分开保存。
- 使用 OpenAI、Groq、自定义 OpenAI 兼容云服务或本机运行的 LM Studio，首次使用需自行选择模型。
- 管理类型翻译词典，以及可选的标题人名显示词典。
- 执行媒体库任务，查看进度和失败原因，在恢复条件满足时撤销字段应用。
- 管理页面支持简体中文和英文菜单。

应用后的标题、简介和类型是 **所有用户共享的 Jellyfin 元数据**。当前仅支持电影条目，不提供按用户切换显示语言的功能。

## 使用边界

先备份 Jellyfin，再用小型测试媒体库检查。应用之前必须关闭该媒体库的元数据保存器；插件无法确认保存器已关闭时会拒绝写入。NFO 仅作为原文来源读取，插件不会重写原始 NFO。

标题必须先确认原文。当现有片名与 `OriginalTitle` 不一致时，可能需要在「来源与历史」中手动确认。确认会分别记录原文和当前显示，不会立即改名；之后的外部改名仍需要审查。简介必须来自归属明确、具有非空 `<plot>` 的本地电影 NFO，不能直接把数据库中的简介当作原文。多段视频的 NFO 归属使用 Jellyfin 的附加部分关系判断。

本预览版直接适配 **Jellyfin 12.0.0**，不兼容旧版本。其他 Jellyfin 版本、Linux、Docker 和 NAS 尚不在支持范围。云服务密钥使用 Windows 当前用户 DPAPI 加密，保存密钥的 Windows 账户必须与运行 Jellyfin 的账户一致。

## 开始使用

1. 阅读[安装与首次使用](docs/INSTALL.md)。
2. 了解[发送给翻译服务的数据](docs/PRIVACY.md)。
3. 按[备份与恢复说明](docs/BACKUP.md)保留完整数据。
4. 从源码构建请参阅[开发说明](docs/DEVELOPMENT.md)。

首次使用建议按「选择电影库 → 配置服务与模型 → 确认一部影片的原文 → 生成、检查、应用 → 测试恢复」完成一遍。

自定义云服务使用通用 OpenAI Chat Completions 格式：在设置中填写 HTTPS API 基础地址和模型 ID，先保存服务设置，再使用随包工具保存该服务独立的密钥并测试连接。JSON 输出模式可选，默认不发送厂商专属的推理参数。模型列表可读取不代表翻译一定可用，应先试一部影片。

当前没有插件订阅源或自动更新渠道；ZIP 用于手动安装插件，不包含 Jellyfin Server 安装程序。
