开始使用 Metadata Localizer

新版使用独立数据目录。创建数据库后，选择管理的媒体库并配置连接。

检测到旧版或其他分支数据。它们保留在原目录，新版不会导入或覆盖这些数据。请先保留旧版备份。

当前进度

优先复用已有译文；可用结果自动显示。保留原文和空字段不计入覆盖分母。

最近任务

失败/暂停为批次历史记录；当前待处理项见下方问题列表。
