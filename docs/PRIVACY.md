# Privacy

Sources, immutable translation versions, selections, settings, dictionary/person rules, work, request evidence and display journals live in the plugin's versioned directory. Keys are separate endpoint-bound CurrentUser DPAPI envelopes. No key is returned to the browser or serialized into task diagnostics. Backups contain private metadata and encrypted credentials: do not publish them.

Generating sends the selected original text, applicable protected names and prompt context to the configured public HTTPS Chat Completions service. Model listing sends the key to that endpoint but no movie text. The optional translation test sends a fixed word after confirmation. Provider retention and billing depend on that service. There is no model-type filtering or automatic provider fallback.

The endpoint policy rejects local/private addresses, redirects and proxies and validates public destination addresses. Only administrators access management endpoints. NFO/media files are not uploaded as files or modified; selected textual fields are sent for requested translation.

Request evidence stores state, timing, usage, result and validation diagnostics. Phase timing headers and observation counters contain only phase names/durations/counts. Unknown outcomes are preserved and require explicit acknowledgement before retrying.

Public source and packages exclude databases, real media, credentials, local paths, logs, backups and personal-fork operational records. Tests use synthetic content and fake transports; no production access or real generation is required.
